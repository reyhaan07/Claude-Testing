Part XIII

Networking from
an OS Perspective

To an application, sending data across the world looks like writing to a file descriptor. This part opens that abstraction: how a socket becomes a packet, how the kernel network stack and the NIC cooperate, and how servers handle a hundred thousand connections at once.
In this part: The network stack · Sockets & the socket API · Socket file descriptors · TCP vs UDP · Kernel networking · Interrupts & DMA in packet processing · Network buffers · Blocking vs non-blocking sockets · High-performance networking (epoll, C10K)
