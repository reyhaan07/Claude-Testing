⚑Revision Tip
For each pair, memorize one discriminating sentence — the row that truly separates them: "mutex has an owner, semaphore doesn't"; "paging = internal fragmentation, segmentation = external"; "a hard link shares the inode, a symlink stores a path"; "concurrency is structure, parallelism is execution." Lead with that line, then expand only if pressed.
