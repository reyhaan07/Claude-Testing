Memory: Paging, Translation, TLB

Problem 3 — Address translation

Given: page size = 1 KB (1024 bytes), and the page table maps page 1 → frame 20. Translate logical address 1500.

  • Offset bits: 1024 = 210 → 10-bit offset.
  • Page number = ⌊1500 / 1024⌋ = 1;   offset = 1500 − 1024 = 476.
  • Page 1 → frame 20. Physical address = 20 × 1024 + 476 = 20480 + 476 = 20956.

Problem 4 — Address-space sizing

Given: 32-bit logical addresses, 4 KB pages. (a) How many entries in a single-level page table? (b) How many offset bits?

  • Offset: 4 KB = 212 → 12 offset bits.
  • Page number bits = 32 − 12 = 20 → entries = 220 = 1,048,576 entries per process. (This is why multi-level page tables exist — Part VII.)

Problem 5 — TLB effective access time

Given: TLB access 20 ns, memory access 100 ns, TLB hit ratio 80%. The TLB is checked on every reference.

EAT = 0.8×(20+100) + 0.2×(20+2×100) = 0.8×120 + 0.2×220 = 96 + 44 = 140 ns

On a miss you pay the TLB check plus a page-table read (100 ns) plus the data access (100 ns) = 220 ns. Higher hit ratios push EAT toward 120 ns.

⚑Exam Strategy
Always (1) draw the Gantt chart / head path first, (2) read off Completion Times / boundaries, (3) then apply the formulas mechanically. Most lost marks come from a wrong Gantt chart or forgetting idle time / direction — not from the arithmetic. Show every step; partial credit is real.
