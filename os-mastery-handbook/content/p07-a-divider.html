Part VII

Memory
Management

RAM is a single shared array of bytes, yet every process believes it owns a private, contiguous memory from address zero. Memory management is the machinery — addresses, page tables, and the MMU — that makes that comfortable illusion real and safe.
In this part: Logical vs physical vs virtual addresses · Address binding · Contiguous allocation · Fixed & variable partitioning · Internal & external fragmentation · Compaction · Paging (pages, frames, page tables) · Address translation · TLB · Multi-level & inverted page tables · Segmentation
