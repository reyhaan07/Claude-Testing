Part XIV

Linux Practical OS

Theory becomes intuition when you can see it. This part is a hands-on tour of the Linux commands and virtual file systems that let you watch processes, memory, scheduling, and I/O in a live kernel — every command tied back to the concept it reveals.
In this part: ps, top, htop · kill, nice, renice · jobs, fg, bg · lsof · df, du, free · vmstat, iostat · strace, dmesg · /proc, /dev, /sys
